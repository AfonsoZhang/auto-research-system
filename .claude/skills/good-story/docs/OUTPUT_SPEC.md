# Output Specification

This file describes the expected output shape for `good-story`.

## Default Story Card

Use this English template for internal story artifacts. Localize only the final user report or an explicitly requested deliverable under [the language policy](../../shared-references/research-autonomy.md#working-language).

```markdown
## Best story

## Why this story works

## Story spine

## Evidence map

| Claim | Evidence | Boundary |
|---|---|---|

## Weak points

## Rewrite targets
```

## Field Calibration Add-On

Use when the user is working across fields or asks whether the skill applies to a field.

```markdown
## Field calibration

- Evidence category of the supplied materials:
- Evidence standards in this field:
- Supported claim strength:
- Field implications:
- Main reviewer concerns:
```

## Candidate Story Add-On

Use for early projects.

```markdown
## Candidate stories

| Rank | Story | Strengths | Risks |
|---|---|---|---|
```

## Figure Order Add-On

Use when the user provides a figure list.

```markdown
## Recommended figure order

| Order | Figure | Role in the argument |
|---|---|---|

## Gaps
```

## Rebuttal Add-On

Use when the user asks for reviewer resistance.

```markdown
## Reviewer concerns

| Objection | Severity | Repair path |
|---|---|---|

## Better-supported wording
```

## Hard Requirements

- Do not invent evidence.
- Do not turn correlation into causation.
- Do not hide negative results or limitations.
- Do not use stronger claim verbs than the evidence supports.
- For the final Chinese user report, avoid English framework labels unless they prevent ambiguity. Internal artifacts remain English.
